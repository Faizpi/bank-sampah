# Roadmap

1. Validasi teknis kanal web dan implementasi lokal Telegram untuk tiga role; pertahankan Admin di web.
2. Review keamanan independen serta UAT warga/pengurus nyata pada prototype; perbaiki istilah, langkah, dan kesalahan yang teramati.
3. Selaraskan Bab III dan instrumen penelitian dengan implementasi yang benar-benar diuji; SUS/perbandingan Web vs Telegram membutuhkan peserta nyata.
4. Setelah persetujuan privasi dan penerapan, lengkapi token/webhook HTTPS/scheduler pada server. Deployment tetap keputusan terpisah.

Telegram nonaktif secara default sampai konfigurasi dan persetujuan siap. Penimbangan dan serah fisik tetap kegiatan langsung, tetapi hasilnya dapat dicatat lewat web atau bot memakai layanan domain yang sama. Jangan menganggap produksi sudah terhubung; WhatsApp tidak digunakan.
